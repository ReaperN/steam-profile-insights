# Code of Conduct

## Our Standard

Contributors are expected to treat each other with respect and to communicate
constructively. Harassment, discrimination, personal attacks, threats, and
deliberate disruption are not acceptable.

Feedback should address the code, documentation, or proposal rather than the
person. Assume good intent, ask clarifying questions, and help keep
discussions welcoming to people with different levels of experience.

## Enforcement

Project maintainers may edit, remove, or close contributions that violate this
standard. Repeated or serious violations may result in temporary or permanent
loss of participation privileges.

Report conduct concerns privately to the project maintainer through GitHub
private communication. Do not include sensitive credentials or personal data
in a public issue.

This code of conduct applies to project spaces, issues, pull requests, code
reviews, and other project-related communication.
